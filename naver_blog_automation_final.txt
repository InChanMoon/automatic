# 네이버 블로그 자동화 시스템 최종 기획서

## 1. 프로젝트 개요

### 목적
네이버 블로그에 글을 대량으로 자동 발행하는 시스템

### 핵심 흐름
```
키워드 입력 → AI가 글 N개 생성 → 사용자 검토/이미지 추가 → 특정 계정에 자동 발행
```

## 3. 프로그램 1: 콘텐츠 생성기

### 3.1 기능

1. **키워드 + 생성 개수 입력**
   - 키워드: "yatpor 사기"
   - 개수: 1~100+ (사용자 자유 설정)
   - 스타일: 정보성/후기형/비교분석
   - 길이: 짧게(500자)/보통(1000자)/길게(1500자+)

2. **AI 대량 생성**
   - 지정 개수만큼 글 생성
   - 각 글마다 제목, 구조, 표현, 예시 전부 다르게
   - 진행률 표시

3. **검토 및 수정**
   - 생성된 글 목록 보기
   - 개별 글 수정/삭제/재생성
   - 이미지 지정 (공통 또는 개별)

4. **발행 설정**
   - 발행할 계정 선택
   - 배분 방식 (한 계정에 전부 / 여러 계정에 분산)
   - 발행 간격 설정

5. **발행큐 등록**
   - Google Sheets 발행큐에 작업 등록

### 4.2 안티봇탐지 설정

```python
from playwright.sync_api import sync_playwright
from playwright_stealth import stealth_sync

def create_browser():
    playwright = sync_playwright().start()
    
    browser = playwright.chromium.launch(
        headless=False,  # 눈으로 확인
        args=[
            "--disable-blink-features=AutomationControlled",
            "--disable-infobars",
            "--disable-dev-shm-usage",
            "--disable-browser-side-navigation",
            "--disable-gpu",
            "--no-sandbox",
            "--disable-extensions",
            "--lang=ko-KR",
            "--window-size=1920,1080",
        ]
    )
    
    context = browser.new_context(
        viewport={"width": 1920, "height": 1080},
        locale="ko-KR",
        timezone_id="Asia/Seoul",
        user_agent="Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/120.0.0.0 Safari/537.36",
    )
    
    page = context.new_page()
    
    # playwright-stealth 적용
    stealth_sync(page)
    
    return playwright, browser, context, page
```

**적용된 우회 기법:**
- `playwright-stealth` - navigator.webdriver 제거, 핑거프린트 위장
- `--disable-blink-features=AutomationControlled` - 자동화 탐지 차단
- User-Agent 실제 크롬 값으로 설정
- locale, timezone 한국으로 설정
- viewport 고정으로 일관된 환경

### 4.3 입력 방식 (send_keys 사용 금지)

```python
import pyperclip
import time
import random

def paste_text(page, selector, text):
    """클립보드 복사 후 Ctrl+V로 붙여넣기"""
    
    pyperclip.copy(text)
    page.click(selector)
    time.sleep(random.uniform(0.3, 0.7))
    page.keyboard.press("Control+v")
    time.sleep(random.uniform(0.5, 1.2))
```

## 5. IP 관리

### 5.1 방법 1: 안드로이드 USB 테더링

```python
import subprocess

def change_ip_android():
    """안드로이드 폰 비행기모드 토글로 IP 변경"""
    
    # 비행기모드 켜기
    subprocess.run(["adb", "shell", "cmd", "connectivity", "airplane-mode", "enable"])
    time.sleep(3)
    
    # 비행기모드 끄기
    subprocess.run(["adb", "shell", "cmd", "connectivity", "airplane-mode", "disable"])
    time.sleep(5)
    
    # USB 테더링 재활성화 (필요시)
    subprocess.run(["adb", "shell", "svc", "usb", "setFunctions", "rndis"])
    time.sleep(3)
    
    return get_current_ip()
```

### 5.2 방법 2: 프록시

```python
class ProxyManager:
    def __init__(self, proxy_list):
        self.proxies = proxy_list
        self.current_index = 0
    
    def get_next_proxy(self):
        proxy = self.proxies[self.current_index]
        self.current_index = (self.current_index + 1) % len(self.proxies)
        return proxy
    
    def apply_to_browser(self, browser_context):
        proxy = self.get_next_proxy()
        # Playwright에 프록시 적용
        return proxy
```

| G | status | 상태 | 생성중/검토중/승인완료/발행완료 |
| H | created_at | 생성일 | 2024-01-15 10:00 |

3. iframe 전환 후 에디터 조작 가능한지
4. 글 발행까지 완료되는지

"""
테스트기 요구사항:
